## 🛠️ Requirements

You can practise the examples using:

* Git
* GitHub account
* Bitbucket account
* Visual Studio Code
* Git Bash
* Windows PowerShell or Command Prompt
* Any terminal application

## 🚀 How to Use

1. Install Git on your computer.
2. Open or download the PDF document.
3. Read the explanation for each topic.
4. Create a practice project folder.
5. Run the provided Git commands.
6. Create branches and practise merging changes.
7. Connect your local project to GitHub or Bitbucket.
8. Practise the complete add, commit, pull, and push workflow.

## 💻 Basic Git Workflow

```bash
git pull
git status
git add .
git commit -m "Describe the change"
git push
```

## 🔐 Important Security Note

Never upload passwords, API keys, database credentials, `.env` files, or other confidential information to GitHub or Bitbucket.

Use a `.gitignore` file to prevent private files from being tracked.
